## Problem 1: Find the Longest Word

Write a function that returns the longest word in a sentence.

If multiple words have the same maximum length, return the first one.

### Example

longest_word("Python is an amazing language")

Output:

"amazing"

### Concepts

- strings
- split
- comparison

## Problem 2: Count Even and Odd Numbers

Write a function that returns the count of even numbers and odd numbers in a list.

### Example

count_even_odd([1, 2, 3, 4, 5, 6])

(3, 3)

## Problem 3: Check if a String Contains Only Digits

Write a function that returns `True` if every character in the string is a digit.

Otherwise, return `False`.

### Example

only_digits("12345")

Output:

True

only_digits("12a45")

Output:

False

### Concepts

- strings
- traversal
- conditions

## Problem 4: Merge Two Sorted Lists

Given two sorted lists, return a new sorted list containing all elements.

Do **not** use `sort()`.

### Example

merge_sorted([1, 3, 5], [2, 4, 6])

Output:

[1, 2, 3, 4, 5, 6]

- arrays
