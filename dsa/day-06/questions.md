## Problem 1: Linear Search

Write a function that returns the index of a target element in a list.

Return `-1` if the element is not present.

### Example

linear_search([4, 8, 1, 9], 1)

Output:

2

### Concepts

- loops
- index traversal
- early exit

## Problem 3: Check if All Elements are Unique

Return `True` if all elements in a list are unique.

### Example

all_unique([1, 2, 3, 4])

Output:

True

all_unique([1, 2, 2, 4])

False

### Concepts

- lists
- membership checking
