# Day 8

## Opportunity 1: Find the Most Frequent Element

Given a list of integers, return the element that appears the most times.

You may assume there is exactly one answer.

### Example

most_frequent([1, 2, 2, 3, 3, 3, 1])

Output:

3

### Concepts

- dictionaries
- frequency counting
- traversal

## Opportunity 3: Find the Intersection of Two Lists

Return a list of unique elements present in both lists.

### Example

intersection([1, 2, 3, 4], [3, 4, 5, 6])

Output:

[3, 4]

### Concepts

- sets
- membership checking
- filtering

## Opportunity 4: Count Words in a Paragraph

Given a sentence, return a dictionary containing the frequency of each word.

Ignore case.

### Example

word_count("Python is fun and python is powerful")

Output:

{
    "python": 2,
    "is": 2,
    "fun": 1,
    "and": 1,
    "powerful": 1
}

### Concepts

- dictionaries
- strings
- splitting text
