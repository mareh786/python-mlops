# Day 9 

## Problem 1: Move All Zeros to the End

Given a list of integers, move all the zeros to the end while maintaining the relative order of the non-zero elements.

### Example

move_zeros([0, 1, 0, 3, 12])

Output:

[1, 3, 12, 0, 0]

### Concepts

- arrays
- traversal
- building a new list

## Problem 2: Find the Largest Odd Number

Write a function that returns the largest odd number in a list.

Return `None` if no odd number exists.

### Example

largest_odd([2, 7, 4, 9, 6])

Output:

9

### Concepts

- loops
- conditions
- running maximum

## Problem 3: Reverse Words in a Sentence

Given a sentence, return a new sentence with the order of the words reversed.

### Example

reverse_words("I love Python")

Output:

"Python love I"

### Concepts

- strings
- split

## Problem 4: Find the Second Smallest Number

Write a function that returns the second smallest distinct number in a list.
