## Problem 1: Find the Difference Between Largest and Smallest

Write a function that returns the difference between the largest and smallest numbers in a list.

### Example

```python
difference([8, 2, 10, 5])
```

Output:

```text
8
```

Explanation:

```
10 - 2 = 8
```
