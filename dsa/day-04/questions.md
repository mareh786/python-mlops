## Problem 1: Check if a List is Sorted

Write a function that returns `True` if a list is sorted in ascending order, otherwise `False`.

### Example

check_sorted([1, 2, 3, 4, 5])

Output:

True

### Concepts

- loops
- adjacent elements
- early exit

## Problem 2: Find the Index of an Element

Write a function that returns the index of a target element in a list.

Return `-1` if the element does not exist.

### Example

find_index([10, 20, 30, 40], 30)

Output:

2

### Concepts

- index traversal
- loops
- conditions

## Problem 3: Remove Duplicates from a List

Return a new list containing only the first occurrence of each element.

### Example

remove_duplicates([1, 2, 2, 3, 1, 4])

Output:

[1, 2, 3, 4]

### Concepts

- lists
- membership checking
- building a new list
