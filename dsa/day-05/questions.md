## Problem 1: Find the Second Largest Number

Write a function that returns the second largest number in a list.

You may assume the list contains at least two distinct elements.

### Example

second_largest([10, 5, 8, 20, 15])

Output:

15

### Concepts

- loops
- comparison
- tracking multiple values
