## Problem 1: Check Palindrome String

Write a function that checks if a string is a palindrome.

Example:
is_palindrome("madam") → True

Concepts:
strings, loops, reverse logic

## Problem 2: Find Maximum in a List

Example:
find_max([3, 5, 1, 9, 2]) → 9

Concepts:
loops, comparison

Example:
